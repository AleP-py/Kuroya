⛏️ Comandos de Minería y Pesca

🔨 Comandos de Crafteo

!craft Forja herramientas avanzadas con materiales.

🐾 Comandos de Mascotas

!pet adopt Adopta una nueva mascota para tu aventura.
!pet feed Alimenta y cuida el estado de tu mascota.

🛡️ Comandos de Moderación

!ban Expulsa permanentemente a un usuario problemático.
!kick Saca a un usuario del servidor temporalmente.

🎉 Comandos de Diversión

!roll Lanza dados y pon a prueba tu suerte.

📜 Comandos de Logs

!setlogs Establece el canal para los registros del bot.

⚙️ Comandos de Utilidades

!ping Muestra la latencia actual del bot.

🪙 Comandos de Economía Global

!daily Reclama tu recompensa diaria de monedas.
!work Trabaja para ganar un ingreso extra inicial.
!balance Revisa tu saldo actual de dinero y riquezas.

❓ Preguntas Frecuentes

¿Cómo consigo un saldo inicial para empezar?

Puedes ejecutar los comandos !daily y !work para obtener tus primeras monedas. Después, puedes seguir minando, pescando y vendiendo ítems para hacer crecer tu fortuna.

¿Cómo reporto un error o sugiero mejoras?

Si encuentras algún error o tienes una idea genial para Kuroya, puedes unirte al servidor de soporte oficial de Discord para reportarlo directamente.
